## 核心思路

附件看起来是一串颜文字，但结构与 Brainfuck 高度一致。根据重复结构建立替换表：

- `( ͡° ͜ʖ ͡°)` → `+`
- `( ͡°(` → `[`
- `) ͡°)` → `]`
- `ᕦ( ͡°ヮ ͡°)ᕥ` → `>`
- `(> ͜ʖ(∩ ͡° ͜ʖ ͡°)⊃━☆ﾟ.*)` → `.`
- `(♥ ͜ʖ♥)` → `-`
- `(∩ ͡° ͜ʖ ͡°)⊃━☆ﾟ.*` → `<`

替换后得到标准 Brainfuck 程序：

```text
++++++++++[>+>+++>+++++++>++++++++++<<<<-]>>>>++++++++++.+++++++.--------------------..++.+++++++++++++++++.--------------.+++++++++++++++++++++.-------------------------.++++++++++++++++.<------------------.---.>----.--------.+++++++++++++++.------------------.++++++++.------------.+++++++++++++++++.<.>+++++.--.++++++++++.
```

用 Brainfuck 解释器执行，输出：

```text
nuaactf{br41nfuck_p1us}
```

## 通用技法

遇到由颜文字、单词、图标等构成的“奇怪语言”，先观察重复 token 与 `[]<>+-.` 的结构规律。只要能建立 token→Brainfuck 指令映射，就可以统一交给通用解释器执行。
