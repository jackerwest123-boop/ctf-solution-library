## 通用处理流程
1. 启动题目独立场景并记录目标 URL。
2. 使用 `curl -i`、浏览器开发者工具、Burp Suite 检查首页、响应头、Cookie、源码、静态资源、LocalStorage、robots.txt、备份文件和可疑参数。
3. 按题名指向的漏洞类型做最小化无破坏验证。
4. 只在动态场景验证成功后回填 `verification.flag`。
5. 未验证题统一保持 blocked-carded，后续由本地 Agent 或人工复现补全。
