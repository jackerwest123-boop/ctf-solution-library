## 题面
听说有五个很厉害的人，一个是 admin，一个是 admin1，一个是 admin2，一个是 admin3，一个是 admin4。听说打败他们其中一个就可以拿到 flag，flag 格式为 `NUAACTF{.*}`。

## 分析过程
该题是账号接管/密码重置类题。Bugku 详情页公开评论给出关键线索：重置 admin 密码，爆破随机数种子，登录 admin。另有评论指出邮件发送流程可能不稳定，因此真实复现需要围绕找回密码 token、时间戳和 PHP 随机数种子生成逻辑展开。

当前无法启动动态场景或触发邮件流程，因此不能获得有效 token 和最终 flag。为避免编造 flag，本题先沉淀为 blocked 状态和通用“密码重置随机数种子爆破”能力卡。

## 解题步骤
1. 启动场景，枚举用户 `admin`、`admin1`、`admin2`、`admin3`、`admin4`。
2. 触发找回密码或重置密码功能，抓取请求和响应。
3. 观察 token 是否与时间戳、`mt_rand`、邮箱验证码或 session 相关。
4. 若 token 使用 PHP 伪随机数生成，使用已知 token 和时间窗口爆破 `mt_rand` 种子。
5. 预测 admin 的重置 token，重置密码后登录。
6. 进入管理员页面读取 flag。
